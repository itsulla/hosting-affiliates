What the site measures—and what it does not

An independent field guide for turning AI-generated application code into a reviewed, secure, maintainable deployment.

Scope

DeployApp.guide loads analytics from analytics.lekker.design and typography resources from Fontshare and Google Fonts. Affiliate click measurement records the provider, page, CTA position, selected model or tool when available, calculator result when available, destination origin/path, and relationship type. Query parameters and referral codes are intentionally excluded from the analytics destination field.

Affiliate click events

When a marked sponsored link is clicked, the site emits an affiliate_click event. The destination field contains only the destination origin and path. Referral codes, query parameters, credentials, and form contents are not copied into that field.

External services

Fonts, analytics, code libraries, and merchant destinations can receive ordinary request information such as IP address, user agent, referrer, and timestamp under their own policies. Following an external link moves you to that provider's privacy and cookie practices.

Accounts and forms

This static publication does not provide reader accounts, accept payments, or collect contact-form submissions. Browser or analytics storage may still be used by loaded third-party services according to their configuration.

Sensitive information

Never submit passwords, API keys, private source code, customer data, wallet keys, or credentials through a public correction route.
