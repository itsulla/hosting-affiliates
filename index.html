Deployment Guides

Practical workflows to get your AI-generated app from code to live URL. Pick the path that matches how you built your app.

A

Push to GitHub

For someone who has never used Git before

1

Create a GitHub account

Sign up at github.com if you haven't already.

2

Open Cursor's terminal

Press Ctrl+` (backtick) to open the integrated terminal.

3

Initialize Git & commit

git init
git add .
git commit -m "Initial commit from Cursor"
4

Create a GitHub repo & push

Go to github.com/new, create a repo (don't add README), then run:

git remote add origin https://github.com/YOU/REPO.git
git branch -M main
git push -u origin main
B

Deploy to Railway

Best for Python, Docker, fullstack apps

1

Go to railway.app → Sign in with GitHub

2

Click "New Project" → "Deploy from GitHub repo"

3

Select your repo. Railway auto-detects the language via Nixpacks.

4

Go to Variables tab → add every key-value pair from your .env file.

5

Click "Generate Domain" for a free .up.railway.app URL. Done!

Alt

Deploy to Vercel

Best for Next.js / React frontend apps

1

Go to vercel.com → Sign in with GitHub

2

Click "Add New Project" → Import your GitHub repo

3

Vercel auto-detects Next.js/Vite. Add Environment Variables if needed.

4

Click Deploy. Get a live .vercel.app URL in ~60 seconds.

Remember: Vercel Hobby = non-commercial only. Upgrade to Pro ($20/mo) if monetizing.
A

Bolt Built-in Deploy (Netlify)

Fastest — one click, no Git required

1

In your Bolt.new project, click the "Deploy" button in the top bar.

2

Bolt uses its Netlify integration to deploy the WebContainer output directly.

3

You get a live Netlify URL immediately. Custom domains supported via Netlify dashboard.

Advantage: Netlify allows commercial use on the free tier — you can monetize immediately.
B

Export to GitHub

For long-term ownership and flexibility

1

Click "Connect to GitHub" in Bolt to push the WebContainer state to a new repo.

2

Authorize Bolt to create a repository on your GitHub account.

3

Once on GitHub, deploy to Vercel, Netlify, or Railway using standard CI/CD.

4

Optionally, clone into Cursor for deeper refinement before deploying.

Tip: Bolt apps built with WebContainers can hit OOM errors for large projects. Export to Cursor early if complexity grows.
A

Lovable Built-in Hosting

One-click publish with Supabase backend

1

Click "Publish" in the Lovable editor. Your app goes live instantly.

2

Lovable auto-provisions a Supabase backend with Auth + Postgres database.

3

Uses Test and Live environments — dev changes don't corrupt production DB.

Trade-off: Deep Supabase lock-in. Scaling costs tied to Supabase pricing, not just hosting.
B

Export to GitHub → Vercel/Netlify

More control, same Supabase backend

1

Use Lovable's GitHub sync to export the React codebase to a repo.

2

Import the repo into Vercel or Netlify.

3

Critical: Add these environment variables on the hosting platform:

VITE_SUPABASE_URL=your-project-url
VITE_SUPABASE_ANON_KEY=your-anon-key
4

Without these keys, the app builds but auth and database silently fail.

DNS Explained Simply

What is DNS?

DNS is the internet's phone book. When someone types yourapp.com, DNS translates that name into the IP address of your server. Without it, users would need to memorize numbers like 76.76.21.21.

Why does it take time?

When you change DNS records, the update needs to spread across thousands of servers worldwide — this is called propagation. Modern changes often work within minutes, but full global propagation can take up to 48 hours.

A

A Record

Maps your domain directly to an IP address. Used for your root domain (e.g., example.com).

example.com → A → 76.76.21.21
CNAME

CNAME Record

Maps a subdomain to another domain name (not an IP). Used for www or app.example.com.

www.example.com → CNAME → cname.vercel-dns.com
TXT

TXT Record

Used for verification. Hosting platforms ask you to add a TXT record to prove you own the domain before issuing SSL certificates.

NS

Nameservers

Point your domain's nameservers to your host (e.g., Vercel, Netlify) to give them full DNS control — simpler but less flexible than managing individual records.

Connecting a Custom Domain

V

Vercel

  1. Go to project → Settings → Domains
  2. Enter your domain. Vercel suggests adding both apex + www.
  3. Vercel shows the required DNS records.
  4. At your registrar, add the A record (apex) and/or CNAME (www).
  5. Or: change nameservers to Vercel's for full delegation.
  6. SSL is provisioned automatically.
N

Netlify

  1. Go to Domain management → Add custom domain
  2. Verify ownership if prompted.
  3. Add A/CNAME records at your registrar, or switch to Netlify DNS nameservers.
  4. SSL is automatic via Let's Encrypt.
R

Railway

  1. Go to service → Settings → Networking
  2. Click "Generate Domain" first for a .up.railway.app URL.
  3. Click "Add Custom Domain" and enter yours.
  4. Railway shows a CNAME value to add at your registrar.
  5. SSL is automatic.

Key Content Strategy

Most vibe coders build React/Next.js (from Bolt, v0) or Python/Flask (from Cursor). Traditional hosts offering high CPAs (Bluehost/Hostinger) are frustrating for these modern stacks.
